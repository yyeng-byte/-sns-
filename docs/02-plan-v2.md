# 기획 v2 (확정 방향)

## 목표
한 대시보드에서 채널별·콘텐츠별 성과 확인 → 전 기간 대비 증감 → 원인 분석 → 급상승 발굴 → 소재·키워드 추천 → 초안 자동 제작 → 발행 일정 관리.

## 화면 (왼쪽 메뉴 6개, 상단 브랜드·기간 필터)
성과 / 분석(왜?) / 급상승 / 추천 / 제작 / 플래너

## 결정 사항
- 데이터 저장: 구글 시트 (회사 계정으로 만들고 관리자 이관). 구조는 `01-sheet-design.md` 유지 (콘텐츠 ID로 연결)
- 자동 업로드: **보류** (자동 "제작"=문구·구성안·초안까지만)
- 네이버 블로그: 통계 엑셀 업로드 + 초안은 복사해서 발행
- 분석 원칙: 숫자로 먼저 분해(도달·반응률·클릭, 채널, 포맷, 발행 수) → Claude는 해석·제안만, 근거 숫자 병기
- 배포: Cloudflare Pages (`public/` 폴더가 정적 사이트), AI 호출은 서버 함수로만

## 단계
1. 뼈대 (가짜 데이터) ← 현재
2. 실데이터 연결 (유튜브 → 비틀리 → 인스타 → 블로그 엑셀)
3. 분석 기능 실제화 (증감·원인·급상승, Claude 해설)
4. 추천·제작 실제화 (Claude)
5. 자동 업로드 (유튜브/인스타, 보류)

## 미해결 질문
- 분석 보강 시 요일·시간대, 소재 분류, 제목 유형 추가 여부
- 접근 제어: Cloudflare Access(회사 이메일) 사용 여부
