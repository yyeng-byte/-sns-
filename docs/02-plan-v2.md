# 기획 v2 (확정 방향)

## 목표
한 대시보드에서 채널별·콘텐츠별 성과 확인 → 전 기간 대비 증감 → 원인 분석 → 급상승 발굴 → 소재·키워드 추천 → 초안 자동 제작 → 발행 일정 관리.

## 화면 (왼쪽 메뉴 6개, 상단 브랜드·기간 필터)
성과 / 분석(왜?) / 급상승 / 추천 / 제작 / 플래너

## 결정 사항
- 데이터 저장: ~~구글 시트~~ → **Cloudflare D1로 변경** (표 구조는 `01-sheet-design.md`를 기준으로 하되 `schema/sheet-schema.json`이 최신, 콘텐츠 ID로 연결)
- 자동 업로드: **보류** (자동 "제작"=문구·구성안·초안까지만)
- 네이버 블로그: 통계 엑셀 업로드 + 초안은 복사해서 발행
- 분석 원칙: 숫자로 먼저 분해(도달·반응률·클릭, 채널, 포맷, 발행 수) → Claude는 해석·제안만, 근거 숫자 병기
- 배포: Cloudflare Pages (`public/` 폴더가 정적 사이트), AI 호출은 서버 함수로만

## 단계
1. 뼈대 (가짜 데이터) ← 현재
2. 실데이터 연결 (유튜브 → 비틀리 → 인스타 → 블로그 엑셀)
3. 분석 기능 실제화 (증감·원인·급상승, Claude 해설)
4. 추천·제작 실제화 (Claude)
5. 자동 업로드 (유튜브/인스타, 보류)

## 미해결 질문
- 분석 보강 시 요일·시간대, 소재 분류, 제목 유형 추가 여부
- 접근 제어: Cloudflare Access(회사 이메일) 사용 여부

## 업데이트: 기존 대시보드 참고 (sns-flow-dashboard)
- 비틀리 링크 규칙은 **기존 방식 유지**: 제목 앞글자로 분류 (키즈링크/키즈유튜브/키즈블로그, 실버링크/실버유튜브/실버블로그/실버카페)
- 기존 대시보드는 그대로 두고, 이 프로젝트의 '성과' 화면을 그 구성을 참고해 재설계
  - 운영 현황: 채널 탭, 핵심 인사이트 배너, KPI 5개, 추이, 특이사항, BEST/RECENT/RISING 하이라이트
  - 유입·링크 순위: 기간 프리셋(1/3/6/12개월·직접), 채널 탭, 유입수, 추이, 채널별 막대, 링크 순위 + 원인 해설, CSV 내려받기
- 실버에듀넷은 '네이버 카페' 채널(비틀리 클릭만)이 추가됨
- 참고 후보(미반영): 이슈 센터, 링크 만들기, 유입 키워드, 작년 동기간 비교, 경쟁 벤치마크

## 업데이트: 실데이터 연결(유튜브·인스타) 구현
- 저장소 구조: `public/`(화면) · `functions/`(서버 함수: 시트 읽기/쓰기, 수집) · `schema/`(시트 양식 정의) · `sheet-template/`(시트 양식 엑셀) · `tests/`(가짜 API 테스트) · `.github/workflows/`(자동 수집·과거 채우기)
- 저장소(DB): 구글 시트 대신 **Cloudflare D1** 로 변경 (시트·서비스 계정 불필요, 콘텐츠 성과 자동 저장, 엑셀은 CSV 내려받기)
- 표 추가: `channel_daily`(채널 일별 성과), `content_metrics`(콘텐츠 성과 스냅샷), `_sync`(수집 기록). 정의는 `schema/sheet-schema.json`, 생성 SQL은 `migrations/0001_init.sql`
- 설정 방법: `docs/03-실데이터-연결-안내.md`
