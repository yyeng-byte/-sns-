# 유튜브·인스타 실데이터 연결 안내 (비개발자용)

> 코드는 모두 만들어져 있습니다. 아래 **준비물 5가지**만 갖추면 연결됩니다.
> 키(비밀번호 같은 것)는 **채팅에 붙여넣지 말고**, 6단계의 Cloudflare 화면에만 입력하세요.

## 전체 흐름 (한 줄 요약)
`유튜브·인스타` → (매일 아침 자동 수집) → `구글 시트` → `대시보드`

## 1단계. 구글 시트 만들기 (회사 구글 계정)
1. 구글 드라이브에서 `sheet-template/SNS대시보드_시트양식.xlsx` 를 업로드합니다.
2. 파일을 열고 **파일 → Google 스프레드시트로 저장**을 누릅니다. (탭 10개가 보이면 정상: 설명, contents, channel_daily …)
3. 주소창의 `https://docs.google.com/spreadsheets/d/`**`여기 긴 글자`**`/edit` 가 **시트 ID**입니다. 메모해 두세요.
4. 나중에 이 시트를 회사 담당자에게 넘길 때는 **공유 → 소유권 이전**을 하면 됩니다.

## 2단계. 구글 서비스 계정 (대시보드가 시트를 읽고 쓰는 "로봇 계정")
유튜브 OAuth를 이미 만들어 둔 **그 구글 클라우드 프로젝트**에서 진행하면 새 프로젝트가 필요 없습니다.
1. 구글 클라우드 콘솔 → **API 및 서비스 → 라이브러리 → Google Sheets API → 사용**
2. **IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기** (이름: `sns-dashboard`)
3. 만든 서비스 계정 → **키 → 키 추가 → JSON** 으로 키 파일을 내려받습니다. (이 파일은 비밀입니다)
4. 서비스 계정의 이메일(`…@….iam.gserviceaccount.com`)을 1단계 시트에 **편집자로 공유**합니다.

## 3단계. 유튜브 (이미 OAuth 설정됨)
필요한 값: **클라이언트 ID, 클라이언트 보안 비밀, 브랜드별 리프레시 토큰 2개**(키드키즈 채널용, 실버에듀넷 채널용)
- 토큰에 허용된 권한(스코프)이 아래 **두 가지**를 포함해야 합니다. 기존 토큰이 `yt-analytics.readonly`만 있다면 `youtube.readonly`를 더해 다시 발급해야 합니다.
  - `https://www.googleapis.com/auth/yt-analytics.readonly`
  - `https://www.googleapis.com/auth/youtube.readonly`
- 토큰 발급이 어렵다면 "유튜브 토큰 재발급 도와줘"라고 말해 주세요. 화면 캡처를 보며 안내하겠습니다.
- 참고: 유튜브는 '도달(노출)' 수치를 API로 주지 않아서 **도달 = 조회수**로 저장합니다.

## 4단계. 인스타그램 (Meta Graph API)
1. developers.facebook.com → **앱 만들기**(유형: 비즈니스) → 제품에 **Instagram Graph API / Facebook 로그인** 추가
2. 필요한 권한: `instagram_basic`, `instagram_manage_insights`, `pages_show_list`, `pages_read_engagement`
   - 관리자 본인이 소유한 계정은 **앱 심사 없이(개발 모드)** 사용할 수 있습니다.
3. 브랜드별 **인스타그램 프로페셔널 계정 ID**(숫자)와 **액세스 토큰**을 준비합니다.
   - 일반 토큰은 약 60일 후 만료됩니다. 회사 운영용으로는 **비즈니스 관리자 → 시스템 사용자** 토큰(만료 없음)을 권장합니다.
4. 인스타 계정은 **프로페셔널(비즈니스/크리에이터) 계정이며 페이스북 페이지에 연결**되어 있어야 합니다.

## 5단계. Cloudflare Pages 만들기
1. Cloudflare → **Workers & Pages → 만들기 → Pages → Git 연결** → 이 저장소 선택
2. 빌드 설정: **빌드 명령 없음**, **빌드 출력 디렉터리 = `public`**
3. **설정 → 변수 및 비밀(Secrets)** 에 아래 값을 입력합니다.

| 이름 | 값 |
|---|---|
| `SHEET_ID` | 1단계의 시트 ID |
| `GOOGLE_SA_EMAIL` | 2단계 JSON 파일의 `client_email` |
| `GOOGLE_SA_KEY` | 2단계 JSON 파일의 `private_key` (통째로) |
| `YT_CLIENT_ID`, `YT_CLIENT_SECRET` | 3단계 |
| `YT_REFRESH_TOKEN_KK`, `YT_REFRESH_TOKEN_SE` | 3단계 (키드키즈/실버에듀넷) |
| `IG_USER_ID_KK`, `IG_TOKEN_KK` | 4단계 키드키즈 |
| `IG_USER_ID_SE`, `IG_TOKEN_SE` | 4단계 실버에듀넷 |
| `COLLECT_SECRET` | 직접 정하는 긴 임의 문자열 (자동 수집 암호) |

4. **Cloudflare Access**(회사 이메일로만 접속)를 사이트에 걸어 주세요. 대시보드에 회사 데이터가 보이므로 필수입니다.

## 6단계. 자동 수집 켜기 (GitHub Actions)
1. GitHub 저장소 → **Settings → Secrets and variables → Actions**
   - Secret `COLLECT_SECRET`: 5단계와 **같은 문자열**
   - Variable `SITE_URL`: 배포된 사이트 주소 (예: `https://xxxx.pages.dev`)
2. **Actions → 매일 자동 수집 → Run workflow** 를 **dry=1**(테스트)로 먼저 실행합니다. 시트에는 아무것도 쓰지 않고 "무엇을 가져오는지"만 로그에 나옵니다.
3. 오류가 없으면 **dry=0**으로 실행 → 시트의 `channel_daily`, `contents`, `content_metrics` 탭에 데이터가 생깁니다.
4. 이후 **매일 한국시간 08:30**에 자동 실행됩니다. 결과는 시트 `_sync` 탭에 기록됩니다.
5. 대시보드를 열었을 때 왼쪽 아래에 **"✅ 실데이터 연결됨"** 이 보이면 성공입니다.

## 7단계. 작년 데이터 채우기 (작년 동기 대비를 쓰려면)
**Actions → 과거 데이터 채우기 → Run workflow** : `source`(youtube/instagram), `from`/`to`(예: 2025-09-01 ~ 2025-11-30)
- 유튜브는 과거 데이터가 충분히 남아 있습니다.
- 인스타는 Meta가 제공하는 과거 기간이 짧을 수 있습니다(지표별 상이). 첫 실행 결과로 확인해야 합니다.
- 팔로워/구독자 수는 과거 구간에서 복원이 불가능해 비워 둡니다(수집을 시작한 날부터 쌓임).

## 알아둘 점 (솔직한 한계)
- 이 코드는 **가짜 구글/유튜브/메타 서버로 동작을 검증**했습니다. **실제 계정으로는 첫 실행(dry=1)에서 처음 확인**됩니다. Meta는 지표 이름이 자주 바뀌어, 첫 실행에서 일부 지표가 `_sync` 탭의 메시지에 경고로 나올 수 있고, 그 경우 바로 수정하겠습니다.
- 아직 **샘플인 것**: 경쟁사, 소재·키워드 추천, 블로그, 비틀리 클릭. (다음 단계에서 연결)
- Cloudflare 무료 플랜은 한 번 실행에 외부 호출 50회 제한이 있어, 브랜드·채널별로 나눠서 호출하도록 만들었습니다.
- 이 저장소와 GitHub Actions가 개인 계정(`yyeng-byte`)에 있다면, 회사에 두고 가실 때 회사 조직 저장소로 옮기고 6단계 값을 다시 입력해야 합니다.
