# 유튜브·인스타 실데이터 연결 안내 (비개발자용)

> 코드는 모두 만들어져 있습니다. 아래 **준비물**만 갖추면 연결됩니다.
> 키(비밀번호 같은 것)는 **채팅에 붙여넣지 말고**, Cloudflare 입력 화면에만 넣으세요.
> 구글 시트·서비스 계정은 **필요 없습니다**. 숫자는 Cloudflare 데이터베이스(D1)에 자동 저장됩니다.

## 전체 흐름 (한 줄 요약)
`유튜브·인스타` → (매일 아침 자동 수집·저장) → `Cloudflare 데이터베이스` → `대시보드`
- 채널 일별 성과와 **콘텐츠별 성과는 사람이 입력하지 않아도 매일 자동으로 저장**됩니다. 새 게시물은 콘텐츠 ID(예: `KK-YT-261005-01`)가 자동으로 붙습니다.
- 엑셀로 보고 싶으면 대시보드 왼쪽 아래의 **엑셀로 받기** 링크를 누르면 됩니다.

## 1단계. Cloudflare 데이터베이스(D1) 만들기
1. Cloudflare → **Storage & Databases → D1 → 데이터베이스 만들기** (이름: `sns-dashboard`)
2. 만든 데이터베이스 → **Console** 탭 → `migrations/0001_init.sql` 파일 내용을 **통째로 붙여넣고 실행**합니다. (표가 10개 만들어집니다)

## 2단계. 유튜브 (이미 OAuth 설정됨)
필요한 값: **클라이언트 ID, 클라이언트 보안 비밀, 브랜드별 리프레시 토큰 2개**(키드키즈 채널용, 실버에듀넷 채널용)
- 토큰 권한(스코프)에 아래 **두 가지**가 있어야 합니다. 기존 토큰에 `yt-analytics.readonly`만 있다면 `youtube.readonly`를 더해 다시 발급해야 합니다.
  - `https://www.googleapis.com/auth/yt-analytics.readonly`
  - `https://www.googleapis.com/auth/youtube.readonly`
- 토큰 발급이 어렵다면 "유튜브 토큰 재발급 도와줘"라고 말해 주세요. 화면 캡처를 보며 안내하겠습니다.
- 참고: 유튜브는 '도달(노출)' 수치를 API로 주지 않아서 **도달 = 조회수**로 저장합니다.

## 3단계. 인스타그램 (Meta Graph API)
1. developers.facebook.com → **앱 만들기**(유형: 비즈니스) → 제품에 **Instagram Graph API / Facebook 로그인** 추가
2. 필요한 권한: `instagram_basic`, `instagram_manage_insights`, `pages_show_list`, `pages_read_engagement`
   - 관리자 본인이 소유한 계정은 **앱 심사 없이(개발 모드)** 사용할 수 있습니다.
3. 브랜드별 **인스타그램 프로페셔널 계정 ID**(숫자)와 **액세스 토큰**을 준비합니다.
   - 일반 토큰은 약 60일 후 만료됩니다. 회사 운영용으로는 **비즈니스 관리자 → 시스템 사용자** 토큰(만료 없음)을 권장합니다.
4. 인스타 계정은 **프로페셔널(비즈니스/크리에이터) 계정이며 페이스북 페이지에 연결**되어 있어야 합니다.

## 4단계. Cloudflare Pages 만들기
1. Cloudflare → **Workers & Pages → 만들기 → Pages → Git 연결** → 이 저장소 선택
2. 빌드 설정: **빌드 명령 없음**, **빌드 출력 디렉터리 = `public`**
3. **설정 → Functions → D1 데이터베이스 바인딩**: 변수 이름 **`DB`**, 데이터베이스 **`sns-dashboard`**
4. **설정 → 변수 및 비밀(Secrets)** 에 아래 값을 입력합니다.

| 이름 | 값 |
|---|---|
| `YT_CLIENT_ID`, `YT_CLIENT_SECRET` | 2단계 |
| `YT_REFRESH_TOKEN_KK`, `YT_REFRESH_TOKEN_SE` | 2단계 (키드키즈/실버에듀넷) |
| `IG_USER_ID_KK`, `IG_TOKEN_KK` | 3단계 키드키즈 |
| `IG_USER_ID_SE`, `IG_TOKEN_SE` | 3단계 실버에듀넷 |
| `COLLECT_SECRET` | 직접 정하는 긴 임의 문자열 (자동 수집 암호) |

5. **Cloudflare Access**(회사 이메일로만 접속)를 사이트에 걸어 주세요. 대시보드에 회사 데이터가 보이므로 필수입니다.

## 5단계. 자동 수집 켜기 (GitHub Actions)
1. GitHub 저장소 → **Settings → Secrets and variables → Actions**
   - Secret `COLLECT_SECRET`: 4단계와 **같은 문자열**
   - Variable `SITE_URL`: 배포된 사이트 주소 (예: `https://xxxx.pages.dev`)
2. **Actions → 매일 자동 수집 → Run workflow** 를 **dry=1**(테스트)로 먼저 실행합니다. 저장은 하지 않고 "무엇을 가져오는지"만 로그에 나옵니다.
3. 오류가 없으면 **dry=0**으로 실행합니다. 대시보드를 열었을 때 왼쪽 아래에 **"✅ 실데이터 연결됨"** 이 보이면 성공입니다.
4. 이후 **매일 한국시간 08:30**에 자동 실행됩니다. 실행 기록은 데이터베이스 `_sync` 표에 남습니다.

## 6단계. 작년 데이터 채우기 (작년 동기 대비를 쓰려면)
**Actions → 과거 데이터 채우기 → Run workflow** : `source`(youtube/instagram), `from`/`to`(예: 2025-09-01 ~ 2025-11-30)
- 유튜브는 과거 데이터가 충분히 남아 있습니다.
- 인스타는 Meta가 제공하는 과거 기간이 짧을 수 있습니다(지표별 상이). 첫 실행 결과로 확인해야 합니다.
- 팔로워/구독자 수는 과거 구간에서 복원이 불가능해 비워 둡니다(수집을 시작한 날부터 쌓임).

## 알아둘 점 (솔직한 한계)
- 이 코드는 **가짜 유튜브/메타 서버 + 진짜 SQL 데이터베이스(SQLite)** 로 동작을 검증했습니다. **실제 계정으로는 첫 실행(dry=1)에서 처음 확인**됩니다. Meta는 지표 이름이 자주 바뀌어, 첫 실행에서 일부 지표가 경고로 나올 수 있고, 그 경우 바로 수정하겠습니다.
- 아직 **샘플인 것**: 경쟁사, 소재·키워드 추천, 블로그, 비틀리 클릭. (다음 단계에서 연결)
- Cloudflare 무료 플랜은 한 번 실행에 호출 횟수 제한이 있어, 브랜드·채널별로 나눠서 호출하도록 만들었습니다.
- 이 저장소와 GitHub Actions가 개인 계정(`yyeng-byte`)에 있다면, 회사에 두고 가실 때 회사 조직 저장소로 옮기고 5단계 값을 다시 입력해야 합니다. Cloudflare 계정도 인수인계가 필요합니다(회사 사람을 관리자로 초대하고 본인이 빠지기).
